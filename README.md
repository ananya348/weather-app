# 🌤️ Weather App

A simple and responsive Weather Application built using **Python, Flask, HTML, CSS, and JavaScript**. The application allows users to search for a city and view its current weather information using a weather API.

## 📌 Features

- 🌍 Search weather by city
- 🌡️ Current temperature
- 💧 Humidity information
- 💨 Wind speed
- ☁️ Weather condition
- 📅 5-day weather forecast
- 📱 Responsive design
- ⚡ Real-time weather data

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Weather API**
